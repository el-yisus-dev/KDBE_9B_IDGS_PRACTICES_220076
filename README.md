## Description

This repository contains the practices, assignments, research, and projects developed during the **Knowledge Extraction from Databases** course.

The main objective of this course is to learn how to obtain useful information and knowledge from databases through data collection, preprocessing, analysis, data mining, and machine learning techniques.

## Repository Organization

Each practice is developed in its own Git branch following the naming convention:

```text
practica_1
practica_2
practica_3
practica_4
practica_5
...
```

This approach allows each practice to be managed independently while maintaining a clean and organized repository history.

To view a specific practice:

```bash
git checkout practica_5
```

To list all available branches:

```bash
git branch -a
```
